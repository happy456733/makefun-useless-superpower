A tiny Node program that writes one original one-liner about a hilariously useless superpower to entry.txt — built for make.fun's "One Line, Zero Use: The Useless Superpower Sprint" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes a single original line (under 200 characters) to `out/entry.txt`. Deterministic, with zero network requests and no dependencies.
